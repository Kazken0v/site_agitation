# 🕵️ Кабинет детектива — «ЭТО НЕ САЙТ»

Мрачный интерактив в духе Gravity Falls `This Is Not A Website Dot Com`:
чёрный экран с паролем → ночной кабинет (стол, лампа, окно с дождём на canvas, молнии)
→ CRT-терминал кодов → всплывающие улики → главный пароль → победа + книга имён.

## Где лежит
Папка `site_agitation` на Рабочем столе.

## Как запустить (2 способа)

### 1. Просто открыть (без установки, бэкенд не нужен)
Дважды кликни `index.html` — игра работает локально, победители хранятся в браузере.

Пароли-заглушки:
- вход: `дождь`
- коды: `ворон`, `02:47`, `ключ`, `письмо`, `след`
- главный пароль: `noir1947`

### 2. С бэкендом (проверка на сервере + общая книга победителей)
```bash
node --version   # нужен Node 18+
cd backend
npm install
npm start
# открыть http://localhost:3000
```

## Как вписать СВОИ вопросы
1. Открой `questions.js` — перепиши `code / hint / clue_title / clue_text / piece`.
2. Скопируй то же самое в `backend/questions.json` (чтобы сервер и локалка совпадали).
3. `piece` — буквы главного пароля по порядку. Например 5 улик дали `П О Б Е Д` + год → `finalPassword: "побед1947"`.
4. `finalHint` — подсказка к главному паролю.

Проверка: регистр и лишние пробелы не важны, `Нуар-1947` = `noir1947`.

## Свои картинки и звуки (папки media/ и sounds/)
- Картинка улики: положи файл в `media/`, например `media/перо.jpg`,
  и укажи в вопросе `"clue_media": "media/перо.jpg"`.
- Звук дождя: положи `sounds/rain.mp3` — сайт сам его подхватит (иначе сгенерирует шум кодом).
- Где брать бесплатно: pixabay.com, freesound.org, unsplash.com (дождь, гром, нуар-стол).

## Файлы
- `index.html` — вся сцена
- `style.css` — мрак, стол, CRT
- `rain.js` — дождь + молнии (canvas)
- `sound.js` — дождь/гром/гудок без файлов
- `terminal.js` — игра, попапы, победа
- `questions.js` — ТВОИ ВОПРОСЫ
- `backend/server.js` + `questions.json` + `winners.json` — сервер и книга имён
